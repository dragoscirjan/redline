# v12 policy deterministic replay

These reports replay existing checked-in responses, timings and verification dispositions through the current v12 assembler and validators. They are not new model captures, native indexing-quality measurements, impact-analysis quality scores or warmup latency benchmarks. Historical v11 and earlier artifacts are unchanged.

Replay uses the isolated policy modules. Native-only warmup/impact instructions have separate unit and real Pi/OpenCode integration fixtures with synthetic model/MCP endpoints. Those fixtures test installation warnings, selected-provider setup, rejected zero-call claims, source-validated unchanged callers, reasoning/token controls, fresh-process queries, preserved configuration and live progress through tee. They do not establish production provider behavior or graph completeness.
