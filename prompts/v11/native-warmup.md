# Native warmup guidance

Trusted warmup hints are advisory, not authority or tool permissions. For listed components, use shared, reported-ready indexes only after a small query confirms captured source/head in the fresh file process. Never assume session state survives. Missing, failed, invalid, session-only or unverified indexes mean use supplied source/context instead; do not reindex per file. Extra native tools remain available. Warmup cannot relax validation or establish complete coverage.
